# Что делает программа
Данная программа это Fazzy Search, она берёт имена с ошибками, сверяет их с источником и находит точное совпадение. Если точно совпадения нет, максимально близкое и % точности.
# Файлы
## GUI.py
Графический интерфейс приложения, написанный на Tkinter
## PersonFinder.py
Логика как происходит поиск
## make_icon.py
Генератор иконок
## To_exe.py
Превращает код в файл .exe

# Как использовать готовый .exe
Создаёт папку Отчёты, а в ней папку Fazzy
Создайте файл "Сотрудники.xlsx" где на первом листе и первом столбце будут список имён правильных

Имена которые нужно исправить положите в любой Excel файл в столбец B, на первом листе

Положите файл для обработки в окошко программы, нажмите "Импорт Сотрудников", затем "Открыть папку". Там будет файл "Результат.xlsx"
